# 魔光打字通

适用于 Windows ACT 原生版、ACT 国服整合和呆萌 ACT 的魔光键影自动输入插件。插件直接读取游戏中的 `KTGEWord` / `KTGInput` 界面结构，逐只怪物输入中文题目、回车攻击，并等待输入框或题目状态确认后继续。

## 运行条件

- 已能正常记录日志的 ACT，包含 `FFXIV_ACT_Plugin`。
- 若要使用悬浮窗，需要安装 `OverlayPlugin/ngld`。
- ACT 与游戏必须使用相同权限等级；若游戏以管理员运行，ACT 也应以管理员运行。

游戏更新可能改变内存结构。若插件页一直显示找不到 `KTGEWord` 或 `KTGInput`，请停止自动攻击并等待兼容更新。

## 一键安装

1. 完全退出 ACT 和相关启动器，任务管理器中不要残留多个 ACT 实例。
2. 解压整个 ZIP，不能只把 DLL 单独拖出来。
3. 双击 `安装到ACT.cmd`。
4. 选择 ACT 根目录：原生版和呆萌 ACT 选择包含 `Advanced Combat Tracker.exe` 的目录，ACT 国服整合选择包含 `CafeACT.exe` 的目录。
5. 安装器会备份 ACT 和 OverlayPlugin 配置，然后复制插件、启用插件并注册名为“魔光打字通”的悬浮窗。
6. 启动 ACT。插件页出现 `KeyboundProbe.ActPlugin.dll` 且状态为已加载，即安装成功。

升级时重复以上步骤即可。已有的 `KeyboundProbe.settings.ini` 会保留，不会被默认设置覆盖。
如果 ACT 安装在受保护目录并提示“拒绝访问”，请右键以管理员身份运行安装脚本。

同一个安装包同时支持 ACT 原生版、ACT 国服整合和呆萌 ACT，不需要按 ACT 类型下载不同 DLL。首次使用原生 ACT 时，请先启动并正常退出一次，让 ACT 生成配置文件后再运行安装器。

## 使用方法

1. 启动 ACT，确认 `FFXIV_ACT_Plugin：已连接`。
2. 启动并切回 FFXIV，游戏必须保持前台。
3. 进入魔光键影玩法。插件页应显示 `KTGEWord 1`，出现小怪后会列出中文题目。
4. 在插件页勾选“启用 ACT 直读自动攻击（逐只确认）”，或在 ngld 悬浮窗点击“自动攻击关闭”。
5. 插件一次只处理一只怪物：聚焦输入框、输入题目、回车提交，检测到输入框清空、题目切换或怪物死亡后才会继续。
6. 需要立即停止时，在插件页点击“立即停用”，或在悬浮窗关闭自动攻击。

攻击参数分为“拟人”“光之战士”“自定义”三种。拟人与光之战士使用固定参数；自定义模式可分别设置反应、每字、提交、总时长上下限和抖动。总时长从选定小怪开始计算，不足下限会在提交前补足，预计超过上限会压缩等待。

默认全局热键 `F1` / `F2` / `F3` 分别切换拟人、光之战士和自定义模式。点击 ACT 页的对应“模式热键”按钮可重新绑定，设置会保存。

防闲置随自动攻击开启：最近 30 秒有输入回读成功时，插件会校验当前玩法和界面 Agent，重置小游戏专用的两个闲置计时值，并读取确认。该功能会写入这 8 字节游戏内存；停用自动攻击、退出小游戏或近期没有成功输入时不再写入。校验、写入或回读失败会停用自动攻击并记录原因。原先定时提交错误拼音的方式已停用。

## 连续自动化（测试性功能）

自动刷本目前作为测试性功能提供。单局流程已完成实机验证，连续多局仍待更多实战验证，首次使用请先设置 1～2 局观察。

在插件页设置“连续刷（测试）”的局数（1～999，默认 1），点击“开始连续流程”。走到键斗广场报名登记员 5 米内后，会自动选中 NPC 并交互，申请参加并确认魔光键影，进入后开启自动答题，结算时点击退出。返回广场且结算界面消失后才计为完成一局；未达到设定局数时，等待 3 秒后继续报名，达到局数后自动停止。选中使用默认 `F12`（最近 NPC/物体），确认目标确为报名登记员后才用小键盘 `0` 交互；请使报名登记员成为最近 NPC，并保持游戏前台。

ACT 页面和 ngld 悬浮窗均显示已完成的局数。点击 ACT 的“中断连续流程”“立即停用”，或悬浮窗的“中断流程”，会立即停止自动输入及后续流程。当前对局或已有排本需要手动处理，中断不会自动退本。局数设置会保存，ACT 重启后不会自动开刷；再次点击开始时从 0 计数。

距离不足、切到其他窗口或按钮暂不可用时会等待；超时、游戏进程改变、防闲置异常或未经结算就返回广场时，整段流程会停止，不会继续排下一局。日志中的 `FLOW_START`、`FLOW_ROUND_COMPLETE` 和 `FLOW_STOP` 记录目标局数及完成计数。

入口会自动开启一次捕获，完成或停止后保存到 `Plugins\KeyboundProbe\Captures`。请一并保留 `.memory.tsv`、`.events.tsv`、`.summary.txt` 和 `KeyboundProbe.auto.log`。若之前已手动开启捕获，流程结束后仍保持捕获。

## 悬浮窗

安装器会自动添加“魔光打字通”，默认尺寸为 `520 × 310`。如果没有出现：

1. 打开 ACT 的 `插件 → OverlayPlugin悬浮窗插件`。
2. 检查列表中是否有“魔光打字通”，确保可见且未禁用。
3. 若自动注册失败，新建 MiniParse/自定义悬浮窗，将 URL 指向：

   `ACT根目录\Plugins\KeyboundProbe\overlay\index.html`

4. 重新加载悬浮窗。`runtime.js` 会在插件每次启动时自动生成，不应从其他电脑复制。

## 设置文件

路径：`Plugins\KeyboundProbe\KeyboundProbe.settings.ini`

| 设置 | 含义 |
| --- | --- |
| `TimingMode` | `human`（拟人）、`warrior`（光之战士）或 `custom`（自定义） |
| `CustomReactionDelayMs` | 自定义模式：选定小怪后的反应时间 |
| `CustomCharacterDelayMs` | 自定义模式：每个字的输入间隔 |
| `CustomSubmitDelayMs` | 自定义模式：完成输入后的提交延迟 |
| `CustomTotalMinimumMs` | 自定义模式：反应、逐字输入和提交的总时长下限 |
| `CustomTotalMaximumMs` | 自定义模式：总时长上限；不得小于下限 |
| `CustomJitterPercent` | 自定义模式：反应、每字、提交和总时长上下限的随机抖动百分比；抖动后仍保证下限不大于上限 |

拟人预设为 `150 / 70 / 150 / 1000 / 3000 ms / 20%`；题目达到 7 字时总时长下限变为 `2000 ms`。光之战士预设为 `50 / 30 / 50 / 500 / 500 ms / 0%`。旧版参数首次读取后会自动迁移，原目标顺序设置不再使用。

修改后可在插件页调整并保存。

## 故障排查

- **ACT 提示日志文件被占用**：关闭所有 ACT 实例，在任务管理器确认没有残留进程后再启动，只能运行一份同目录 ACT。
- **能看到题目但不输入**：保持 FFXIV 在前台，确认自动攻击已开启，并查看插件页的 `KTGInput` 诊断。
- **输入内容错误或乱打**：立即停用；确认使用的是与当前游戏版本匹配的插件，不要同时运行旧桥接或另一份自动输入工具。
- **悬浮窗离线**：先确认 ACT 插件已加载；检查 Windows 防火墙是否阻止 ACT 的本机 `127.0.0.1` 回环通信，然后刷新悬浮窗。
- **被强制退出任务**：保留 `KeyboundProbe.auto.log` 和该局 `.memory.tsv`。检查 `AFK_GUARD` / `BRAWLER_IDLE` 的 `state`、`reason`、`before` 和 `after`；`state=reset` 表示专用计时已写入并回读确认。若为 `blocked`、`write-failed` 或 `readback-failed`，请把整段日志交给作者。仍需完整对局验证是否消除强退。
- **需要反馈**：附上插件版本、游戏版本、问题发生时间，以及 `Plugins\KeyboundProbe\KeyboundProbe.auto.log` 对应时间附近的片段；不要公开完整抓包。

## 文件与隐私

- 自动化日志：`Plugins\KeyboundProbe\KeyboundProbe.auto.log`。
- 网络与只读内存探针在点击“开始捕获”或启动连续流程后写入 `Captures`。
- ngld 控制服务只监听 `127.0.0.1`，每次 ACT 启动会生成新的随机 token，不访问互联网。
- 分发包不包含任何本机日志、抓包、角色数据、token、PDB 或旧版桥接文件。

## 卸载

关闭 ACT 后双击 `卸载.cmd`。卸载器会禁用悬浮窗、移除 ACT 插件注册和程序文件，但保留设置、日志与抓包，便于恢复或排查。
