# 魔光打字通：攻击优先级与机制处理

本文记录 ACT 自动攻击的阶段规则。只有经实战日志确认的实体、读条和状态才写入自动决策；尚未标定的机制先记录，不以猜测 ID 上线。

## P1：击杀 25 只小怪

已实现。

- Director `0x1` 是约 5 秒准备阶段，`0x2` 才允许攻击；它们不是玩法的 P1/P2。
- 语义阶段由连续轮次、击杀数和实体组成识别：进入战斗先按 P1，累计 25 次死亡转 P2，发现 `4C8C` 转 P3；P2 特殊实体也可用于中途接入识别。
- 通关条件：网络死亡事件去重后累计 `25` 只。
- 目标顺序：以 KTGEWord 中第一次观察到实体的顺序为准，先出现先攻击。
- 锁定规则：选中一只后持续处理它的后续题目，直到收到死亡事件再切换下一只。
- 同一批次首次出现多个目标时，以 KTGEWord 的 Addon/槽位顺序作为稳定次序。
- 阶段切换会清空出现顺序、死亡去重集合和进度。

已实现的优先级：

1. 屏障强化实体 `4E6F`：持续攻击到其消失。
2. 必须累计四次攻击的读条：守卫机蝎主加农炮、仙人刺“？针刺”、魔界花“黏菌爆发”。
3. 奖励小怪 `4C88`：出现后优先击杀，死亡后观察到“爆发时间” `14DE`。
4. 导弹 `4D71` 与已知自爆物。
5. 花苞 `4D73` 及出芽后小怪 `4D74`。
6. 当前精英怪或普通小怪；同档仍按先出现先攻击。

特殊暂停：

- 冥鬼之眼 `4C87` 读条“诅咒视线” `C179`：结束前 700ms 停止输入，读条结束后 1 秒再继续；读条被打断则立即取消暂停。
- 视觉妨碍：先记录 KTGEWord/KTGInput 在状态期间是否仍可读，不在证据不足时盲打。

## P3：暴风破坏者

- 实体：`4C8C`，暴风破坏者。
- 屏障 `4E6F`：最高优先级，攻击到其消失。
- 地雷 `4DD3`：读条“爆炸” `C22A`，优先级高于首领、低于屏障和需要四次打断的读条。
- 运动体探知干扰器 `C226`：结束前 700ms 停止输入，读条结束后 1 秒再继续。
- 无读条视觉妨碍：记录状态期间 KTGEWord 与 KTGInput 的可读性。

已观察动作：`C223` 破坏加农炮、`C225` 妨碍、`C226` 运动体探知干扰器、`C227` 霹雳炸弹、`C228` 电光榴弹、`C22E` 导弹发射。
